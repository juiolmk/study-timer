# 学习打卡（StudyTimer）

一个用于**学习计时与习惯记录**的 Windows 桌面应用。极简清爽的顶部导航 + 仪表盘布局，支持浅色/深色与 4 套强调色，零第三方运行时依赖。

## 功能

- **界面**：顶部导航 + 仪表盘首页：大计时器、今日进度环、数据卡、今日任务预览与 7 日趋势；浅色/深色 × 雾蓝/松绿/暮紫/暖橙，设置页可即时切换。
- **今日任务**：按「高 / 中 / 低」优先级记录每天要做的事；点任务直接开始计时，勾选完成；未完成自动顺延到次日，学习记录自动关联任务并汇总时长。
- **计时 / 番茄钟**：自由正向计时，或 25 / 45 / 60 分钟倒计时；倒计时结束自动记录并进入休息（默认 5 分钟短休，每 4 轮 15 分钟长休），休息结束后回到待开始状态；可在设置页关闭自动休息。
- **计时绑定任务**：点任务直接开始计时；没有任务时，开始按钮仍可按设置填写“这次学什么”（可跳过，弹窗居中）。内容会自动带入本次记录与番茄钟自动记录。
- **快速补记**：不启动计时也能 10 秒补一条记录；时长预设 15 / 25 / 45 / 60 分钟，自动带出上次标签，首页与记录页均可进入。
- **今日概览**：今日已学、连续打卡、目标完成度进度环、今日任务预览与近 7 天趋势。
- **学习记录**：标题、标签（科目）、备注、起止时间；关键字搜索 + 标签筛选；补记 / 编辑 / 删除。
- **统计**：区间汇总（累计 / 日均 / 达标 / 最长连续）、趋势柱状图（7 / 14 / 30 天）、近 12 周学习热力图、科目分布。
- **设置**：每日目标、定点提醒、达成提醒、开始前询问开关、默认番茄钟时长、短休 / 长休时长与长休间隔轮数、浅色 / 深色主题与强调色、全局快捷键开关、数据导出 JSON / CSV、导入 / 打开目录 / 清空。
- **全局快捷键**：`Ctrl+Alt+S` 在任意窗口（含应用最小化或失去焦点时）开始 / 暂停 / 继续计时，零第三方依赖，可在设置页关闭。
- **数据安全**：原子写入（临时文件 + 替换）、自动轮转备份（保留最近 7 份）、导入校验、旧版数据自动迁移；主文件损坏时启动自动从备份恢复并提示。

快捷键：`空格`（应用内）＋ `Ctrl+Alt+S`（全局）开始 / 暂停 / 继续计时。若 `Ctrl+Alt+S` 被其他程序占用，应用会自动降级为仅应用内快捷键，并在界面提示一次。

## 运行

需要 Python 3.10+（含 Tkinter，Windows 自带）。

```bash
python app.py
```

## 性能说明

记录页对记录量大时的体验做了专门处理：**Canvas 自绘卡片**，每页只画 50 行；底部“加载更多”按页重绘；删除 / 编辑记录后保留当前已加载页与滚动位置，搜索与标签筛选、切换页面回到首屏。`refresh_all()` 只刷新首页与当前可见页，不再连带刷新隐藏页。

实测口径（Windows，Python 3.14，窗口真实显示；每档独立冷进程，`time.perf_counter()`）：

| 记录数 | App 初始化 | 记录页首屏 | 记录页可见时 refresh_all | 首页可见时 refresh_all | 加载更多 50→100 |
| --- | --- | --- | --- | --- | --- |
| 0 | ~1.1s | 0.004s | 0.002s | 0.002s | — |
| 200 | ~1.14s | 0.045s | 0.043s | 0.007s | 0.066s |
| 1000 | ~1.22s | **0.048s** | **0.048s** | 0.008s | 0.068s |
| 3000 | ~0.91–1.1s | 0.042s | 0.048s | 0.009s | 0.064s |

优化前后（1000 条）：记录页首屏 5.92s → **0.048s**；记录页可见时保存/删除 6.54s → **0.048s**；首页保存后刷新 33ms → **8ms**；加载更多 1.1–1.4s → **0.068s**。App 初始化约 1.1–1.2s，主要是 Tk/字体/其他页面的固定成本，与记录数基本无关。

实现说明：

- 记录行改为 Canvas 图元（卡片、文字、标签、操作区），不再为每行创建 Frame/Label，绕开了 `ScrollableFrame` 内嵌 Canvas 的布局放大（实测 50 行普通 Frame 布局约 67ms，内嵌 Canvas 约 720ms）。
- 交互使用命中区域：单击“编辑/删除”、双击行主体编辑、底部“加载更多”可点击；行内文字按像素宽度截断，不会互相覆盖。
- 3000 条时初始化在 0.91–1.22s 波动，属于 Tk 冷启动噪声；首屏稳定在 ~0.04s。

## 打包为 exe

```bash
pip install pyinstaller
pyinstaller --onefile --windowed --name 学习打卡 --icon assets/study_timer.ico --version-file version_info.txt --add-data "assets/study_timer.ico;assets" --collect-submodules study_timer app.py
```

也可双击 `build.bat` 一键打包。产物：`dist/学习打卡.exe`。

- `--icon` + `--add-data`：exe 文件图标与窗口图标都用 `assets/study_timer.ico`（`--onefile` 需把 ico 一起带上，运行时由 `study_timer/resources.py` 定位）。
- `--version-file`：写入 `version_info.txt` 的中文名称与版本，可在 exe 属性页看到「学习打卡」/ 2.1.0.0。
- 图标是入库的静态资源，**不需要** Pillow；仅在需要改图标时运行 `python tools/make_icon.py`（开发期依赖 Pillow）。

## 数据

- 主文件：`%APPDATA%/StudyTimer/study_data.json`
- 单份备份：`%APPDATA%/StudyTimer/study_data.bak.json`（兼容旧版本）
- 轮转备份：`%APPDATA%/StudyTimer/backups/study_data-时间戳.json`，自动保留最近 7 份
- 运行日志：`%APPDATA%/StudyTimer/logs/app.log`（单文件 1MB，保留 3 份历史；设置页「查看日志」可直接打开）
- 单实例：重复启动会提示“学习打卡已在运行。”并退出，不会开出第二个窗口
- 启动时若主文件损坏或缺失，会依次回退到单份备份与最新轮转备份，并在界面提示“已从备份恢复”。
- 结构版本 `version: 2`；旧版（平铺 settings、`durationMin`、字典形式 checkins）读取时自动迁移。
- 设置页可导出 JSON 与 CSV（`utf-8-sig`，Excel 直接打开不乱码）、导入 JSON（含字段校验）。

```
│       ├── app.py           # 主窗口与页面调度
│       ├── theme.py         # 浅色 / 深色主题
│       ├── widgets.py       # 圆角按钮、卡片、进度环、热力图等
│       └── pages/
│           ├── home.py
│           ├── records.py
│           ├── stats.py
│           └── settings.py
├── tests/                   # unittest 测试
├── tools/
│   └── make_icon.py         # 图标生成脚本（开发期用 Pillow，运行时不需要）
├── build.bat

```

## 技术栈

- Python 3 + `tkinter`（界面）、`json` / `csv`（存储与导出）、`dataclasses`、`unittest`

- 无第三方运行时依赖
