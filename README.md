# 学习打卡（StudyTimer）

一个用于**学习计时与习惯记录**的 Windows 桌面应用。现代化布局，支持浅色/深色主题，零第三方运行时依赖。

## 功能

- **计时 / 番茄钟**：自由正向计时，或 25 / 45 / 60 分钟倒计时；倒计时结束自动记录并进入休息（默认 5 分钟短休，每 4 轮 15 分钟长休），休息结束后回到待开始状态；可在设置页关闭自动休息。
- **计时绑定任务**：开始计时前可轻量填写“这次学什么”与标签（可跳过），内容会自动带入本次记录与番茄钟自动记录；全局快捷键为保持即时，不弹此询问。
- **快速补记**：不启动计时也能 10 秒补一条记录；时长预设 15 / 25 / 45 / 60 分钟，自动带出上次标签，首页与记录页均可进入。
- **今日概览**：今日已学、连续打卡、目标完成度进度环、最近记录。
- **学习记录**：标题、标签（科目）、备注、起止时间；关键字搜索 + 标签筛选；补记 / 编辑 / 删除。
- **统计**：区间汇总（累计 / 日均 / 达标 / 最长连续）、趋势柱状图（7 / 14 / 30 天）、近 12 周学习热力图、科目分布。
- **设置**：每日目标、定点提醒、达成提醒、开始前询问开关、默认番茄钟时长、短休 / 长休时长与长休间隔轮数、浅色 / 深色主题、全局快捷键开关、数据导出 JSON / CSV、导入 / 打开目录 / 清空。
- **全局快捷键**：`Ctrl+Alt+S` 在任意窗口（含应用最小化或失去焦点时）开始 / 暂停 / 继续计时，零第三方依赖，可在设置页关闭。
- **数据安全**：原子写入（临时文件 + 替换）、自动轮转备份（保留最近 7 份）、导入校验、旧版数据自动迁移；主文件损坏时启动自动从备份恢复并提示。

快捷键：`空格`（应用内）＋ `Ctrl+Alt+S`（全局）开始 / 暂停 / 继续计时。若 `Ctrl+Alt+S` 被其他程序占用，应用会自动降级为仅应用内快捷键，并在界面提示一次。

## 运行

需要 Python 3.10+（含 Tkinter，Windows 自带）。

```bash
python app.py
```

## 性能说明

记录页对记录量大时的体验做了专门处理：**只渲染前 50 条**，底部“加载更多”按页追加（只新建新一页的行，不整表重建）；删除 / 编辑记录后保留当前已加载页与滚动位置，搜索与标签筛选、切换页面回到首屏。`refresh_all()` 只刷新首页与当前可见页，不再连带重建隐藏页。

实测口径（Windows，Python 3.14，窗口真实显示；同一脚本内 `time.perf_counter()`，每档独立冷进程）：

| 记录数 | App 初始化 | 记录页首屏（真实） | 首屏（仅控件创建） | 记录页可见时 refresh_all | 首页可见时 refresh_all | 加载更多 50→100 |
| --- | --- | --- | --- | --- | --- | --- |
| 0 | ~1.07s | 0.02s | 0.00s | 6ms | 4ms | — |
| 200 | ~1.38s | 0.60s | 0.10s | 0.80s | 39ms | 0.58s |
| 1000 | ~1.40s | **0.58s** | 0.10s | 0.76s | 33ms | 0.57s |
| 3000 | ~1.39s | 0.65s | 0.11s | 0.82s | 34ms | 0.60s |

优化前后（1000 条）：记录页首屏 5.92s → **0.58s**，App 初始化 6.56s → **1.40s**，首页保存记录后的 `refresh_all` 6.54s → **33ms**；关键点是首屏成本不再随记录数增长（200 / 1000 / 3000 条基本持平）。

需要如实说明的余量：

- **首屏仍有约 0.5s 花在布局上**：Python 侧创建 50 行控件只要约 0.10s，其余是 Tk 布局开销。根因是滚动容器 `ScrollableFrame` 用 Canvas 内嵌 Frame（`create_window`），其布局放大约一个数量级——同样 50 行普通 Frame 布局约 67ms，放进 Canvas 内嵌容器约 720ms。
- 因此“记录页可见时保存 / 删除一条记录”约 0.76s（同样受上述布局放大影响），首页可见时该路径只需 33ms。
- 进一步优化的方向是**换渲染结构**而非继续加索引：记录列表改用 `ttk.Treeview`（虚拟化、原生滚动）或 Canvas 逐行自绘，可绕开内嵌 Frame 的布局放大；本次未做，避免在改动窗口内重写渲染层。

## 打包为 exe

```bash
pip install pyinstaller
pyinstaller --onefile --windowed --name 学习打卡 --collect-submodules study_timer app.py
```

也可双击 `build.bat` 一键打包。产物：`dist/学习打卡.exe`。

## 数据

- 主文件：`%APPDATA%/StudyTimer/study_data.json`
- 单份备份：`%APPDATA%/StudyTimer/study_data.bak.json`（兼容旧版本）
- 轮转备份：`%APPDATA%/StudyTimer/backups/study_data-时间戳.json`，自动保留最近 7 份
- 运行日志：`%APPDATA%/StudyTimer/logs/app.log`（单文件 1MB，保留 3 份历史；设置页「查看日志」可直接打开）
- 单实例：重复启动会提示“学习打卡已在运行。”并退出，不会开出第二个窗口
- 启动时若主文件损坏或缺失，会依次回退到单份备份与最新轮转备份，并在界面提示“已从备份恢复”。
- 结构版本 `version: 2`；旧版（平铺 settings、`durationMin`、字典形式 checkins）读取时自动迁移。
- 设置页可导出 JSON 与 CSV（`utf-8-sig`，Excel 直接打开不乱码）、导入 JSON（含字段校验）。

```
└── README.md
```
